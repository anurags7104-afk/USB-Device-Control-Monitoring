Core components

USB device detection

Detects USB storage connections and shows device details available to Windows.

Policy and alerting

Reports devices classified as unauthorized by the configured policy.

Structured event logs

Stores event records in JSONL format for review and troubleshooting.

File-system auditing

Uses Watchdog to observe file creation, modification, and deletion in a monitored folder.

SHA-256 hashing

Computes a cryptographic hash of accessible file content for integrity review.
